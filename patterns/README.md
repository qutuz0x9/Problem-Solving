# Patterns

This is a cross-reference index of common problem-solving patterns/techniques.
It is **not** the primary organization for solved problems (see `problems/README.md`
for that — problems are organized by platform). Use this index to quickly find every
problem that uses a given pattern, across all platforms and languages.

Each pattern gets its own file: `patterns/<pattern-name>.md`, containing a short
description of the technique and a list of links to problems that use it, e.g.:

```markdown
# Two Pointers

Use two indices moving through a structure (often from opposite ends or at
different speeds) to avoid nested loops.

## Problems
- [leetcode/0001-two-sum](../problems/leetcode/0001-two-sum) (Go)
```
