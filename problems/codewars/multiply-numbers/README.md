# Multiply Numbers

- **Platform:** codewars
- **Language:** python
- **Link:** https://www.codewars.com/kata/57a2f2f512af636650000019
- **Difficulty:** 8 kyu
- **Tags:** array, math, fundamentals

## Problem

Given a list of numbers, return the product of all of them.

## Approach

Single pass, multiplying an accumulator by each element in the list.

## Complexity

- Time: O(n)
- Space: O(1)
